# Code of Conduct

DPG adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text at that link applies to all project spaces: the repository,
issues, pull requests, discussions and any project chat.

## Summary

- Be respectful and constructive. Critique code and ideas, not people.
- No harassment, discrimination, sexualised content, personal attacks or doxxing.
- Never post anyone's real credentials or personal data, including in "examples".

## Reporting

Report conduct issues privately to the maintainers through the contact listed in
[GOVERNANCE.md](GOVERNANCE.md). Reports are handled confidentially. Enforcement follows the
Contributor Covenant 2.1 enforcement guidelines (correction, warning, temporary ban, permanent ban).
