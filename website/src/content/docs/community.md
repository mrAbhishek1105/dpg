## GitHub

Source, issues and discussions: <https://github.com/mrAbhishek1105/dpg>

## Contributing

Read `CONTRIBUTING.md` and the [development guide](/docs/development/). Good starting points are
detection rules with synthetic test fixtures, documentation fixes, and tasks marked
`good first issue`. Never include real credentials in issues, PRs or examples.

## Discussions and issues

- **Questions and ideas:** GitHub Discussions.
- **Bugs:** the bug-report issue template (synthetic data only).
- **Missed secrets or false alarms:** the "Detection gap or false positive" template.

## Security reports

Do **not** open a public issue for a vulnerability. Use GitHub's private vulnerability reporting
(**Security → Report a vulnerability**) on the repository. See `SECURITY.md` for scope and response targets.

## Release notes

`CHANGELOG.md` in the repository, and GitHub Releases once releases exist. No release has been published yet.

## Code of conduct

The project follows the Contributor Covenant 2.1.
