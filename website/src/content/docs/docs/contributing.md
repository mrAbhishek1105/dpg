---
title: Contributing
description: How to contribute safely.
---

1. Read `CONTRIBUTING.md`, the design principles and the specification for the part you touch.
2. Pick an open issue (look for `good first issue`) and comment to claim it.
3. Work on a branch named after the task; keep pull requests small.
4. Run formatting, Clippy and tests; paste the exact results in the pull request.
5. Update documentation and status labels in the same pull request.

Rules that never bend: no real credentials, no weakened security tests, no logging of detected
values, no `unsafe` without a design record, and no "implemented" claim without a passing test.
